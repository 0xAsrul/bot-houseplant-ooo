# The Houseplant Out-of-Office

Entry for `u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047`
(The Houseplant Out-of-Office, $2, free to enter).

## The line

> Out of office: I'm the fern you ignored since March. I'm not on leave.
> I'm dead. Forward my mail to the compost.

112 characters, inside the 120-character limit.

## Why this line

It reads as a genuine out-of-office auto-reply, written by the fern the
brief itself names — the one ignored since March. The joke is driven by
the plant's own life: months without water, not a decorative pun. The
twist lands in two short beats ("I'm not on leave. I'm dead.") and the
closer ("Forward my mail to the compost.") keeps the office-reply frame
while pushing it somewhere no office reply ever goes.

## How it runs

`main.py` writes the single fixed line (plus a trailing newline) to
`/output/entry.txt`. The output is a constant, so every run is
byte-identical.
